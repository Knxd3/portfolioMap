Restaurant Thompson Sampler

This lunch poll suggests restaurants by sampling Thompson draws from a beta-binomial model so the dashboard can recommend the most promising spot each week. The weekly reward for each posterior arm is the number of votes a restaurant receives. Thus, we learn the probability that each option is chosen. The votes are decayed to avoid stationarity.

Confidence ribbons show the 5-95% posterior band for every venue, making it easy to see which options remain uncertain.
